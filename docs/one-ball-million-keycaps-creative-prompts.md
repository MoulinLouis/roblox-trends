# 1 Ball vs 1 Million Keycaps — Creative Generation Prompts

Use these prompts as starting points for A/B tests. Generate the artwork without text whenever possible, then add the game title manually so it stays sharp and readable. Every image should honestly represent the game's top-down 2.5D presentation, real 3D balls, real 3D keycaps, and escalating destruction.

## Thumbnails — 16:9

### 1. The Impossible Scale

**Creative angle:** Make the `1 vs 1,000,000` promise understandable in one glance.

```text
Create a high-CTR 16:9 thumbnail for a Roblox game called "1 Ball vs 1 Million Keycaps". Show a dramatic top-down 2.5D view of one small, intensely glowing red ball entering an enormous arena completely packed with countless colorful 3D mechanical keyboard keycaps. The keycaps must extend far into the distance like an impossible ocean, with a small trail of freshly shattered keycaps directly behind the ball. Use extreme visual contrast between the single ball and the gigantic field, a clean central composition, bright saturated colors, strong rim lighting, crisp toy-like 3D materials, and large readable shapes that remain clear on a small mobile screen. The image should instantly communicate one ball versus one million objects. Reserve a clean area in the upper-left corner for a manually added title. No avatars, no side-view platforming, no flat 2D sprites, no gameplay UI, no tiny unreadable details, no generated text, no logos, no watermark, no photorealism. Cinematic Roblox game thumbnail quality, highly polished, exciting but faithful to actual top-down gameplay, 16:9 aspect ratio.
```
